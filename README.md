# Power BI Sales Analysis Dashboard

## Project Overview
This project analyzes sales data using Microsoft Power BI to understand sales performance, profit, product categories, and customer order patterns.

## Dataset
- **Orders.csv** – Order and customer details.
- **Details.csv** – Sales, profit, quantity, category, sub-category, and payment mode details.

## Tools Used
- Microsoft Power BI
- Power Query
- Data Visualization
- CSV Datasets

## Key Analysis
- Sales and profit analysis
- Category and sub-category performance
- State-wise and city-wise sales
- Quantity analysis
- Payment mode analysis

## Project Files
- `Orders.csv`
- `Details.csv`
- `Sales-Analysis.pbix` – Power BI report file (to be uploaded)

## How to Use
1. Download the dataset files.
2. Open the Power BI report in Power BI Desktop.
3. Update the data source paths if required.
4. Refresh the data to explore the dashboard.
